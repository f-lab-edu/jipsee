# 0010. 건물 검색용 deal_group 요약 테이블

## 상태

- 채택 (2026-11-21)

## 맥락

- "검색" 시 요청마다 거래 행을 조회해 지번 단위로 집계 필요.
- 이 과정은 운영 데이터 기준으로 MySQL에서 '빌라' 검색 시 약 2초 소요 (메모리 4GB 기준)

## 결정

- 건물별 요약 테이블 `deal_group` 추가. 일일 수집 뒤 배치로 갱신
- 검색은 `deal_group`만 조회하고, 상세와 거래 이력은 거래 테이블 조회

## 대안

- Redis 캐시만 추가: 처음 들어오는 검색어는 DB로 가므로 채택하지 않음

## 결과

- '빌라' 검색 약 200ms, 드문 검색어 약 1ms
- 검색 결과는 최대 하루 늦게 반영
