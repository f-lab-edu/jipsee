# 0006. 스키마 관리와 운영 적용

## 상태

- 채택 (2026-11-21)

## 맥락

- 스키마 SQL은 저장소의 `backend/schema`에 보관
- 건물 도메인 제외(0005)로 건축물대장과 매칭용 테이블은 불필요

## 결정

### 새 버전 파일로만 수정

- 이미 적용된 스키마 파일은 수정하지 않음
- 스키마 변경은 새로운 버전의 파일로만 추가

### Flyway 수동 실행과 적용 순서

- Flyway는 수동으로만 실행
- `-target` 옵션으로 하나씩 적용하고 단계마다 결과 확인

## 대안

- 워크플로에 Flyway 추가: 롤백이 어려워서 채택하지 않음

## 결과

- 운영 스키마 변경은 새 버전 파일 추가와 수동 적용으로만 가능
