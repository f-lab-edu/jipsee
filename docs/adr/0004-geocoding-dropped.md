# 0004. 지오코딩 폐기와 같은 법정동 주변 거래

## 상태

- 채택 (2026-11-17)

## 맥락

- 기존 설계는 건축물대장 적재 시 좌표를 저장하고, 좌표 기준으로 주변 거래 조회하는 방식

## 결정

### 지오코딩 폐기

- 스펙 축소
- 좌표와 반경을 사용하지 않고, 문서와 프론트엔드에서도 좌표와 반경 제거
- 주변 거래는 기준 건물과 같은 법정동의 전월세 거래로 조회

## 결과

- 좌표 저장용 `building_location` 테이블 삭제
- 프론트엔드에서 반경과 "위치 정보 없음" 상태 제거
- 같은 법정동의 24개월 거래가 많을 수 있어서 목록을 나누어 조회하는 제한이 필요하며, 세부 내용은 ADR 0008에서 결정
