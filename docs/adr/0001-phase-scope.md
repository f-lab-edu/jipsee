# 0001. 1단계 범위

## 상태

- 채택 (2026-10-25)

## 맥락

- 피드백에 따라 전체 기능을 1단계와 2단계로 구분

## 결정

### 단계별 범위

- 1단계 범위는 실거래 수집, 검색, 상세와 거래 이력, 같은 동 주변 거래, 데이터 출처, 인프라와 운영.
- 2단계 범위는 로그인, 챗봇, 법령

### 2단계 코드와 문서

- 2단계 코드는 삭제하지 않고 유지하며, 1단계 화면에서는 2단계 기능의 진입점 제거
- `docs/`에는 1단계 내용만 유지

## 결과

- `docs/`가 1단계만 설명하므로 2단계 착수 시 커밋 `184fcf5` 시점의 문서를 기준으로 2단계 문서 복원 필요
