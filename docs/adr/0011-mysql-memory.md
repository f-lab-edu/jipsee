# 0011. 운영 MySQL 메모리 상향

## 상태

- 채택 (2026-11-21)

## 맥락

- MySQL 컨테이너 메모리 1GB에서는 거래 테이블과 인덱스(약 1.3GB)가 메모리에 다 올라가지 못함.
- 검색과 요약 테이블 갱신(0010)이 실패

## 결정

- MySQL 컨테이너 메모리를 4GB로 상향
- `innodb_buffer_pool_size`를 3GB로 설정

## 대안

- MySQL 컨테이너 메모리 1GB 유지: 재구성과 검색이 실패하여 채택하지 않음

## 결과

- 데이터와 인덱스가 버퍼 풀에 모두 들어감
- 운영 서버의 여유 메모리로 충분히 감당 가능
