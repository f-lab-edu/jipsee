# 0007. 1단계에서 이용약관과 개인정보처리방침 미노출

## 상태

- 채택 (2026-11-21)

## 맥락

- 이용약관과 개인정보처리방침은 1단계 범위(0001)에서 불필요

## 결정

### 이용약관과 개인정보처리방침 숨김

- `phase2RoutesEnabled` 토글이 false이면 두 화면은 404, 푸터 링크 미노출
- 코드는 유지
- 데이터 출처 화면은 유지

## 대안

- 문서는 1단계에도 공개: 채택하지 않음
- 코드 제거: 나중에 쓸 수도 있어서 채택하지 않음

## 결과

- 토글을 통해 두 화면과 푸터 링크 미노출 처리
