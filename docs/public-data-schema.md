## 법제처 공통

호출 주소: `www.law.go.kr/DRF/lawSearch.do` (목록), `www.law.go.kr/DRF/lawService.do` (본문). 포맷: XML, JSON, HTML (`type`으로 지정하며 생략하면 XML). 공식 가이드: `open.law.go.kr/LSO/openApi/guideList.do`. 이 문서에 적은 관측 값은 2026-10-27에 `OC=test`로 호출해 받은 응답을 기준으로 함.

### 이용 조건

| 항목      | 내용                                                                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 인증      | `OC` 파라미터에 활용 신청 후 승인받은 값을 전달함                                                                                                         |
| 승인      | 모든 데이터는 공동활용 이용 승인을 받은 후에 활용할 수 있음. 승인은 신청 후 1~2일 이내에 처리됨 (이용안내에 기재)                                         |
| 테스트    | `OC=test`로 익명 호출할 수 있음. 호출해 확인한 대상은 `eflaw`, `law`, `lsHstInf`, `lsJoHstInf`                                                            |
| IP 등록   | 승인받지 않은 `OC`로 호출하면 서버 IP 주소와 도메인 주소를 등록하라는 응답이 반환됨. 승인받은 `OC`에 IP 제한이 있는지는 미확인                            |
| 호출 한도 | 공개된 수치가 없음. 이용안내에는 트래픽 초과로 시스템에 부하가 발생하면 제한될 수 있다는 문구만 있음                                                      |
| 건수      | `display` 기본값은 20이고 가이드에 적힌 최대값은 100임                                                                                                    |
| 이용 범위 | 법령정보는 영리 목적 이용을 포함해 자유로운 활용을 보장함 (이용안내에 기재). 상업적 이용이 불가능한 API 목록은 미확인                                     |
| 저작권    | 법령정보의 저작권은 저작권법으로 보호받는 범위 안에서 법제처에 있음 (이용안내에 기재)                                                                     |
| 출처 표시 | 출처를 표기하지 않거나 법제처 이외의 기관을 출처로 명기해 제공하면 저작권법 제137조, 제138조에 따라 형사처벌을 받음 (이용안내에 기재). 출처 표시는 필수임 |

| `연락부서`           | 연락 부서 묶음    | 하위 `부서단위`가 반복됨                                                               |
| `부서단위`           | 연락 부서         | 속성 `부서키`를 가짐. 하위 요소는 `소관부처명`, `소관부처코드`, `부서명`, `부서연락처` |
| `공동부령정보`       | 공동부령 정보     | 빈 값                                                                                  |

- JSON: `부서단위`는 2개이면 배열(주택임대차보호법, 시행령), 1개이면 객체(전세사기피해자 특별법, 민법)임. `소관부처`는 `{"content", "소관부처코드"}` 형태임
- 가이드에 있으나 관측되지 않은 태그: `조문시행일자문자열`, `공동부령구분`, `구분코드`. 미확인

#### 조문

`조문` 아래에 `조문단위`가 반복되며, 속성으로 `조문키`를 가짐.

| 태그             | 한글 의미        | 형식                                                                                              |
| ---------------- | ---------------- | ------------------------------------------------------------------------------------------------- |
| `조문키`(속성)   | 조문 키          | 7자리. 조번호 4자리 + 가지번호 2자리 + 구분 1자리(`1`은 조문, `0`은 전문). `0003021`은 제3조의2   |
| `조문번호`       | 조번호           | 정수 문자열 `3`                                                                                   |
| `조문가지번호`   | 조의 가지번호    | 정수 문자열 `2`. 가지가 없으면 태그가 없음                                                        |
| `조문여부`       | 조문 구분        | `조문`, `전문`                                                                                    |
| `조문제목`       | 조문 제목        | 문자열. 삭제 조문과 `전문`에서는 빈 값                                                            |
| `조문시행일자`   | 조문 시행일자    | `YYYYMMDD`. 관측한 모든 본문에서 요청한 시행일자와 같음                                           |
| `조문제개정유형` | 조문 제개정 유형 | `타법개정`, `일부개정`. 관측한 모든 조문이 법령의 `제개정구분`과 같은 값을 가짐                   |
| `조문이동이전`   | 조문 이동 이전   | 빈 값 또는 `000000`. 의미 미확인                                                                  |
| `조문이동이후`   | 조문 이동 이후   | 빈 값 또는 `000000`. 의미 미확인                                                                  |
| `조문변경여부`   | 조문 변경 여부   | `Y`, `N`. `Y`이면 조문에 변경 내용이 있음 (가이드). `조문이동이전`이 `000000`인 조문은 모두 `Y`임 |
| `조문내용`       | 조문 본문        | 문자열. 아래 표를 참조                                                                            |
| `조문참고자료`   | 조문 참고 자료   | `[전문개정 2008.3.21]`, `[본조신설 2023.4.18]`. 없으면 태그가 없음                                |

`조문내용`은 조문 유형에 따라 다음 형태를 가짐.

| 조문 유형                | `조문내용`                                                                       | `항`                                             |
| ------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------ |
| 항이 없는 조문           | 조문 전체가 들어감. `제1조(목적) 이 법은 ...`                                    | 없음                                             |
| 항이 둘 이상인 조문      | 제목 줄만 들어감. `제3조의2(보증금의 회수)`                                      | 모든 항에 항번호가 있음                          |
| 호만 있는 조문           | 서두 문장이 들어감. `제3조의7(...) ... 다음 각 호의 사항을 ... 제시하여야 한다.` | 항이 1개이며, 항번호와 항내용 없이 `호`만 포함함 |
| 삭제 조문                | `제5조 삭제 <1989.12.30>`                                                        | 없음                                             |
| 전문(편, 장, 절 제목) 행 | 제목 텍스트이며 앞쪽에 공백이 채워짐. `제7절 임대차`                             | 없음                                             |

- 전문 행의 `조문번호`는 바로 뒤에 오는 첫 조문의 번호와 같음
- 전문 행의 `조문키`는 중복될 수 있음. 민법에서 `0001000`은 `제1편 총칙`과 `제1장 통칙`이 함께 사용함 (전문 행 144개에서 둘 이상의 행이 같이 쓰는 키는 26개). 민법의 조문 행 `조문키`는 중복되지 않음
- 개정 표시 `<개정 2013.8.13>`, `<신설 2013.8.13, 2015.1.6>`이 항내용 끝에 포함됨

#### 항, 호, 목

| 태그     | 한글 의미 | 형식                                             |
| -------- | --------- | ------------------------------------------------ |
| `항번호` | 항 번호   | 원문자. `①`~`⑧`이 관측됨                         |
| `항내용` | 항 본문   | 원문자로 시작하는 문자열                         |
| `호번호` | 호 번호   | `1.`                                             |
| `호내용` | 호 본문   | `1.`로 시작하는 문자열                           |
| `목번호` | 목 번호   | `가.`                                            |
| `목내용` | 목 본문   | `가.`로 시작하는 문자열이며 끝에 줄바꿈을 포함함 |

- 계층: `조문단위 > 항 > 호 > 목`. 항 아래에 `항번호`, `항내용`, `호`가, 호 아래에 `호번호`, `호내용`, `목`이 있음
- `항번호`가 있는 항은 `항내용`도 있음. 항이 1개뿐인 조문에서 그 항은 `호`만 가짐
- JSON: `항`은 1개이면 객체(민법 27건), 2개 이상이면 배열(민법 439건). 항이 없는 조문은 키가 없음. 관측한 `호`와 `목`은 모두 2개 이상이라 배열이며, 1개일 때의 형태는 미확인
- 가이드에 있으나 관측되지 않은 태그: `항제개정유형`, `항제개정일자문자열`. 미확인

## 법령 변경이력 목록

엔드포인트: `www.law.go.kr/DRF/lawSearch.do?target=lsHstInf`. 포맷: XML, JSON, HTML. 법령 변경일을 기준으로 변경된 법령의 목록을 반환함.

### 요청

| 파라미터  | 형식                  | 설명                                                                                        |

### 응답

루트 태그는 `LawSearch`임. 루트 값은 `target`, `totalCnt`뿐이며 `page`, `numOfRows`, `resultCode`는 없음 (가이드에 적힌 `page`는 관측되지 않음). 항목 `law`는 `eflaw` 목록의 필드에서 `법령약칭명`, `공동부령정보`를 뺀 구성과 같음.

| 태그           | 한글 의미      | 형식                                                                                 |
| -------------- | -------------- | ------------------------------------------------------------------------------------ |
| `totalCnt`     | 검색 건수      | 정수                                                                                 |
| `법령일련번호` | 법령일련번호   | 숫자 문자열                                                                          |
| `현행연혁코드` | 현행 여부      | `현행`, `연혁`                                                                       |
| `법령명한글`   | 법령명         | 문자열                                                                               |
| `법령ID`       | 법령ID         | 6자리 문자열                                                                         |
| `공포일자`     | 공포일자       | `YYYYMMDD`                                                                           |
| `공포번호`     | 공포번호       | 앞을 0으로 채운 5자리 문자열                                                         |
| `제개정구분명` | 제개정 구분    | `일부개정`, `타법개정`, `전부개정`                                                   |
| `소관부처코드` | 소관부처 코드  | 쉼표로 구분                                                                          |
| `소관부처명`   | 소관부처명     | 쉼표로 구분                                                                          |
| `법령구분명`   | 법령 종류      | `법률`, 부령명                                                                       |
| `시행일자`     | 시행일자       | `YYYYMMDD`                                                                           |
| `자법타법여부` | 자법 타법 여부 | 빈 값                                                                                |
| `법령상세링크` | 본문 조회 경로 | `/DRF/lawService.do?OC=test&target=law&MST=291201&type=HTML&mobileYn=&efYd=20261014` |

- `regDt`는 변경일이므로 공포일자와 다를 수 있음. `regDt=20261015` 결과에는 `공포일자`가 `20261014`, `20261016`인 행이 있음
- 같은 변경일에 같은 법령의 다른 버전 행이 함께 나옴. `regDt=20260317`에서 민법 `001706`이 3행으로 나옴 (MST `265307` 연혁, `251069` 연혁, `284415` 현행)
- 대상 법령을 조회한 사례: 민법 `regDt=20260317`, 전세사기피해자 특별법 `regDt=20260324`(MST `290655`)와 `regDt=20260512`(MST `285963`, `연혁`), 시행령 `regDt=20260623`(MST `287183`)
- `법령상세링크`의 `target`은 `law`이고 `efYd`가 포함됨
- 변경일 데이터가 반영되기까지 지연이 있는지는 미확인
- 0건: `<LawSearch><target>lsHstInf</target><totalCnt>0</totalCnt></LawSearch>`
- JSON: `law`는 1건이면 객체, 2건 이상이면 배열

## 조문 개정이력 목록

엔드포인트: `www.law.go.kr/DRF/lawSearch.do?target=lsJoHstInf`. 포맷: XML, JSON. 가이드에 전일 데이터를 기준으로 제공한다고 적혀 있으므로 개정일 다음 날에 조회해야 함 (예: 2017-10-01 개정분은 2017-10-02에 `regDt=20171001`로 조회).

### 요청

| 파라미터    | 형식          | 설명                                                                          |
| ----------- | ------------- | ----------------------------------------------------------------------------- |
| `OC`        | 문자열        | 필수. 인증값                                                                  |
| `target`    | `lsJoHstInf`  | 필수                                                                          |
| `type`      | `XML`, `JSON` | 가이드에는 필수로 표기됨                                                      |
| `regDt`     | `YYYYMMDD`    | 조문 개정일                                                                   |
| `fromRegDt` | `YYYYMMDD`    | 조회 기간 시작일                                                              |
| `toRegDt`   | `YYYYMMDD`    | 조회 기간 종료일                                                              |
| `ID`        | 법령ID        | 조회 대상을 법령 하나로 제한함. 날짜 없이 `ID`만 보내면 `totalCnt`가 `0`임    |
| `JO`        | 6자리         | 조번호 4자리 + 가지번호 2자리. 호출은 미확인                                  |
| `org`       | 소관부처코드  | 호출은 미확인                                                                 |
| `page`      | 정수          | 기본값 1. `regDt=20260317&ID=001706`로 `page=2`를 요청하면 `totalCnt`가 `0`임 |

확인한 호출: `regDt` 단독, `regDt` + `ID`, `fromRegDt` + `toRegDt` + `ID`.

### 응답

루트 태그는 `LawSearch`이며 `target`, `totalCnt`(개정 조문이 있는 법령 수)를 가짐. 항목 `law`(속성 `id`) 아래에 `법령정보`와 `조문정보`가 있음.

| 태그                   | 한글 의미           | 형식                                                                                        |
| ---------------------- | ------------------- | ------------------------------------------------------------------------------------------- |
| `법령일련번호`         | 법령일련번호        | 숫자 문자열                                                                                 |
| `법령명한글`           | 법령명              | 문자열                                                                                      |
| `법령ID`               | 법령ID              | 6자리 문자열                                                                                |
| `공포일자`             | 공포일자            | `YYYYMMDD`                                                                                  |
| `공포번호`             | 공포번호            | 앞을 0으로 채운 5자리 문자열                                                                |
| `제개정구분명`         | 제개정 구분         | `일부개정`, `타법개정`                                                                      |
| `소관부처코드`         | 소관부처 코드       | 문자열                                                                                      |
| `소관부처명`           | 소관부처명          | 문자열                                                                                      |
| `법령구분명`           | 법령 종류           | `법률`                                                                                      |
| `시행일자`             | 시행일자            | `YYYYMMDD`                                                                                  |
| `jo`(속성 `num`)       | 개정 조문           | `조문정보` 아래에서 반복됨. `num`은 순번임                                                  |
| `조문번호`             | 조번호              | 6자리. 조번호 4자리 + 가지번호 2자리. `037900`은 제379조, `002502`는 제25조의2              |
| `변경사유`             | 변경 사유           | `조문변경`, `본조신설`, `전부개정`. 그 외 값은 미확인                                       |
| `조문링크`             | 조문 본문 경로      | `/DRF/lawService.do?OC=test&target=eflaw&MST=284415&JO=037900&efYd=20260317&type=HTML`      |
| `조문변경이력상세링크` | 조문 이력 상세 경로 | `/DRF/lawService.do?OC=test&target=lsJoHstInf&ID=001706&JO=037900&type=XML`                 |
| `조문개정일`           | 조문 개정일         | `YYYYMMDD`                                                                                  |
| `조문시행일`           | 조문 시행일         | `YYYYMMDD`. 같은 조문이 시행일을 달리해 2행 나올 수 있음 (`002902`: `20260512`, `20261113`) |

- `현행연혁코드`는 없음
- 한 `law` 안에서 `조문시행일`이 서로 다른 조문이 섞일 수 있음 (MST `285963`: `20260512`, `20261113`)
- 대상 법령 사례: 민법 `regDt=20260317&ID=001706`은 조문 7개 (`037900`, `100100`, `100300`, `100402`, `100800`, `101000`, `111500`, 모두 `조문변경`). 전세사기피해자 특별법 `regDt=20260324&ID=014450`은 조문 `001300` 1개. 기간 `20250101` ~ `20261026`에 `ID=014450`을 지정하면 `law` 3개 (MST `277021`, `290655`, `285963`). 시행령 `regDt=20260623&ID=004950`과 주택임대차보호법 `20260101` ~ `20261026`은 0건
- JSON: `law`와 `jo`는 1개이면 객체, 2개 이상이면 배열
- 조문 이력 상세: `lawService.do?target=lsJoHstInf&ID=<법령ID>&JO=<6자리>&type=XML` (가이드에 없음). 루트 태그 `LawService` 아래에 `target`, `totalCnt`, `법령ID`, `법령명한글`, `law`(`법령정보`, `조문정보`)가 있음. `조문정보`는 `조문번호`, `변경사유`(`제정`, `조문변경`), `조문링크`, `조문변경일`을 가짐. 전세사기피해자 특별법 `JO=001300`은 `law`가 3개 (MST `251347` 제정, `265193`, `290655`)
