# 공공데이터 원본 스키마

## 전월세

엔드포인트: `apis.data.go.kr/1613000/RTMSDataSvcRHRent/getRTMSDataSvcRHRent`. 포맷: XML, JSON.

### 요청

| 파라미터     | 형식     | 설명           |
| ------------ | -------- | -------------- |
| `serviceKey` | 문자열   | 인증키         |
| `LAWD_CD`    | 5자리    | 시군구 코드    |
| `DEAL_YMD`   | `YYYYMM` | 계약년월       |
| `pageNo`     | 정수     | 기본값은 1임   |
| `numOfRows`  | 정수     | 기본값은 10임  |
| `_type`      | `json`   | 생략하면 XML임 |

### 응답

| 태그             | 한글 의미                   | 형식                   |
| ---------------- | --------------------------- | ---------------------- |
| `sggCd`          | 시군구 코드                 | 5자리                  |
| `umdNm`          | 법정동                      | 문자열                 |
| `jibun`          | 지번                        | 문자열 또는 숫자. `N`, `N-M`이 아닌 값도 있음(예: `산87-85`, `가-`, `BL-31-4`) |
| `mhouseNm`       | 연립다세대명                | 문자열                 |
| `buildYear`      | 건축연도                    | 4자리                  |
| `excluUseAr`     | 전용면적, 단위 ㎡           | 수치                   |
| `floor`          | 층                          | 정수이며 지하 N층은 `-N`임. 과거 달에는 공백 1자로 오는 행도 있음 |
| `dealYear`       | 계약연도                    | 4자리                  |
| `dealMonth`      | 계약월                      | 1~2자리                |
| `dealDay`        | 계약일                      | 1~2자리                |
| `deposit`        | 보증금액, 단위 만원         | 숫자 또는 콤마가 포함된 문자열 |
| `monthlyRent`    | 월세금액, 단위 만원         | 숫자 또는 콤마가 포함된 문자열(예: `1,070`) |
| `contractTerm`   | 계약기간                    | `YY.MM~YY.MM`          |
| `contractType`   | 계약 구분                   | `신규`, `갱신`         |
| `useRRRight`     | 갱신요구권 사용             | `사용`                 |
| `preDeposit`     | 이전 계약 보증금, 단위 만원 | 숫자 또는 콤마가 포함된 문자열 |
| `preMonthlyRent` | 이전 계약 월세, 단위 만원   | 숫자 또는 콤마가 포함된 문자열(예: `1,070`) |

값이 없는 필드에는 공백 1자 `" "`가 들어감.

## 매매

엔드포인트: `apis.data.go.kr/1613000/RTMSDataSvcRHTrade/getRTMSDataSvcRHTrade`. 포맷: XML, JSON.

### 요청

전월세 요청과 파라미터가 같음.

### 응답

| 태그         | 한글 의미           | 형식                   |
| ------------ | ------------------- | ---------------------- |
| `sggCd`      | 시군구 코드         | 5자리                  |
| `umdNm`      | 법정동              | 문자열                 |
| `jibun`      | 지번                | 문자열 또는 숫자. `N`, `N-M`이 아닌 값도 있음(예: `산87-85`, `가-`, `BL-31-4`) |
| `mhouseNm`   | 단지명              | 문자열                 |
| `buildYear`  | 건축연도            | 4자리                  |
| `excluUseAr` | 전용면적, 단위 ㎡   | 수치                   |
| `floor`      | 층                  | 정수이며 지하 N층은 `-N`임. 과거 달에는 공백 1자로 오는 행도 있음 |
| `dealYear`   | 계약연도            | 4자리                  |
| `dealMonth`  | 계약월              | 1~2자리                |
| `dealDay`    | 계약일              | 1~2자리                |
| `dealAmount` | 거래금액, 단위 만원 | 숫자 또는 콤마가 포함된 문자열 |
| `cdealType`  | 해제 여부           | `O`                    |
| `cdealDay`   | 해제 사유 발생일    | `YY.MM.DD`             |

값이 없는 필드에는 공백 1자 `" "`가 들어감.

같은 필드가 JSON 숫자로도 문자열로도 오므로 둘 다 받아야 함. `mhouseNm`도 숫자로 오는 경우가 있음.

거래가 0건이면 `items`가 빈 문자열 `""`이고, 1건이면 `item`이 배열이 아니라 객체임.

표에 없는 필드가 있음. 전월세는 `houseType`, 매매는 `buyerGbn`, `dealingGbn`, `estateAgentSggNm`, `landAr`, `rgstDate`, `slerGbn`임.

## 법정동코드

파일: data.go.kr 15063424 `국토교통부_전국 법정동`. 포맷: CSV.

### 응답

| 컬럼       | 형식          |
| ---------- | ------------- |
| 법정동코드 | 10자리 문자열 |
| 읍면동명   | 문자열        |
| 리명       | 문자열        |

코드 구조는 앞 2자리가 시도, 앞 5자리가 시군구, 6~8자리가 읍면동, 9~10자리가 리임.

## 대응 키

| 구분         | 전월세, 매매             | 법정동코드                    |
| ------------ | ------------------------ | ----------------------------- |
| 시군구       | `sggCd` (5자리)          | 코드 앞 5자리                 |
| 법정동       | `umdNm` (이름)           | 코드 뒤 5자리, 읍면동명, 리명 |
| 지번         | `jibun` (`N` 또는 `N-M`) | 없음                          |
| 건물명       | `mhouseNm`               | 없음                          |
| 건축연도     | `buildYear`              | 없음                          |
