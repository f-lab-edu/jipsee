## 법정동코드

파일: data.go.kr 15063424 `국토교통부_전국 법정동`. 포맷: CSV.

### 응답

| 컬럼       | 형식          |
| ---------- | ------------- |
| 법정동코드 | 10자리 문자열 |
| 시도명     | 문자열        |
| 시군구명   | 문자열        |
| 읍면동명   | 문자열        |
| 리명       | 문자열        |
| 순번       | 숫자 문자열   |
| 생성일자   | `YYYY-MM-DD`  |

코드 구조: 앞 2자리 시도, 앞 5자리 시군구, 6~8자리 읍면동, 9~10자리 리.
