## 법제처 공통

공식 가이드: `open.law.go.kr/LSO/openApi/guideList.do`. 이 문서의 관측 값은 2026-10-27에 `OC=test`로 호출해 받은 응답을 기준으로 함.

### 이용 조건

| 항목      | 내용                                                                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 인증      | `OC` 파라미터에 활용 신청 후 승인받은 값을 전달함                                                                                                         |
| 승인      | 공동활용 이용 승인을 받아야 활용할 수 있으며, 승인은 신청 후 1~2일 이내에 처리됨 (이용안내에 기재됨)                                                      |
| 테스트    | `OC=test`로 익명 호출할 수 있음                                                                                                                           |
| IP 등록   | 승인받지 않은 `OC`로 호출하면 서버 IP 주소와 도메인 주소를 등록하라는 응답이 반환됨. 승인받은 `OC`에 IP 제한이 있는지는 미확인                            |
| 호출 한도 | 공개된 수치가 없고, 이용안내에는 트래픽 초과로 부하가 발생하면 제한될 수 있다는 문구만 있음                                                               |
| 이용 범위 | 영리 목적 이용을 포함해 자유로운 활용을 보장함 (이용안내에 기재됨). 상업적 이용이 불가능한 API 목록은 미확인                                              |
| 저작권    | 저작권은 저작권법으로 보호받는 범위 안에서 법제처에 있음 (이용안내에 기재됨)                                                                              |
| 출처 표시 | 출처를 표기하지 않거나 법제처가 아닌 다른 기관을 출처로 명기하면 저작권법 제137조, 제138조에 따라 형사처벌을 받음 (이용안내에 기재됨). 출처 표시는 필수임 |

### 공통 응답 규칙

| 항목               | 내용                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| HTTP 상태          | 아래 오류 응답도 모두 상태 코드 200으로 반환됨                                                                                                  |
| 승인받지 않은 `OC` | `<Response><result>사용자 정보 검증에 실패하였습니다.</result><msg>...정확한 서버장비의 IP주소 및 도메인주소를 등록해 주세요.</msg></Response>` |

| XML 텍스트         | 법령 본문은 `<![CDATA[...]]>`로 감싸거나 이스케이프(`&lt;개정 2013.8.13&gt;`)해서 전달함                                                        |

### 민법 임대차 범위

- 임대차 조문은 `조문여부`가 `전문`인 행으로 구분함. 범위를 나타내는 별도 태그는 본문 응답에 없음
- 제7절 임대차 행(`조문번호` 618)부터 다음 `전문` 행인 제8절 고용(`조문번호` 655) 직전까지이며, 제618조부터 제654조까지 37개임
- 제7절 안에는 `전문` 행이 없고 `조문가지번호`가 있는 조문도 없음
- 제651조는 삭제된 조문임 (`제651조 삭제 <2016.1.6>`이며 `조문제목`은 빈 값)

## 법령 본문

엔드포인트: `www.law.go.kr/DRF/lawService.do?target=eflaw`. 포맷: XML, JSON, HTML. `target=law`도 같은 구조로 현행 본문을 반환함.

### 요청

| 파라미터 | 형식                  | 설명                                                          |
| -------- | --------------------- | ------------------------------------------------------------- |
| `OC`     | 문자열                | 필수이며 인증값을 전달함                                      |
| `target` | `eflaw`               | 필수임                                                        |
| `type`   | `XML`, `JSON`, `HTML` | 생략하면 XML임                                                |
| `ID`     | 법령ID                | `ID` 또는 `MST` 중 하나는 필수임. `ID`로는 현행 본문만 반환됨 |

### 응답

루트 태그는 `법령`이고, 속성 `법령키`는 `법령ID`(6), `공포일자`(8), `공포번호`(5)를 이어 붙인 값임 (`0012482025100121065`). 자식 요소는 `기본정보`, `조문`, `부칙`, `개정문`, `제개정이유`이며, 별표가 있으면 `별표`가 추가됨.

#### 기본정보

| 태그          | 한글 의미 | 형식                         |
| ------------- | --------- | ---------------------------- |
| `법령ID`      | 법령ID    | 6자리 문자열                 |
| `공포일자`    | 공포일자  | `YYYYMMDD`                   |
| `공포번호`    | 공포번호  | 앞을 0으로 채운 5자리 문자열 |
| `법령명_한글` | 법령명    | 문자열                       |
| `시행일자`    | 시행일자  | `YYYYMMDD`                   |

- 본문 응답에는 `법령일련번호` 태그가 없음

#### 조문

`조문` 아래에 `조문단위`가 반복됨.

| 태그           | 한글 의미              | 형식                                       |
| -------------- | ---------------------- | ------------------------------------------ |
| `조문번호`     | 조번호                 | 정수 문자열 `3`                            |
| `조문가지번호` | 조번호에 붙는 가지번호 | 정수 문자열 `2`. 가지가 없으면 태그가 없음 |
| `조문여부`     | 조문 구분              | `조문`, `전문`                             |
| `조문제목`     | 조문 제목              | 문자열. 삭제 조문과 `전문`에서는 빈 값임   |
| `조문내용`     | 조문 본문              | 문자열. 아래 표를 참조함                   |

`조문내용`은 조문 유형에 따라 다음 형태를 가짐.

| 조문 유형                | `조문내용`                                                                       | `항`                                             |
| ------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------ |
| 항이 없는 조문           | 조문 전체가 들어감. `제1조(목적) 이 법은 ...`                                    | 항이 없음                                        |
| 항이 둘 이상인 조문      | 제목 줄만 들어감. `제3조의2(보증금의 회수)`                                      | 모든 항에 항번호가 있음                          |
| 호만 있는 조문           | 서두 문장이 들어감. `제3조의7(...) ... 다음 각 호의 사항을 ... 제시하여야 한다.` | 항이 1개이며, 항번호와 항내용 없이 `호`만 포함함 |
| 삭제 조문                | `제5조 삭제 <1989.12.30>`                                                        | 항이 없음                                        |
| 전문(편, 장, 절 제목) 행 | 제목 텍스트가 들어가며 앞쪽에 공백이 채워짐. `제7절 임대차`                      | 항이 없음                                        |

- 개정 표시 `<개정 2013.8.13>`, `<신설 2013.8.13, 2015.1.6>`이 항내용 끝에 포함됨

#### 항, 호, 목

| 태그     | 한글 의미 | 형식                                             |
| -------- | --------- | ------------------------------------------------ |
| `항번호` | 항 번호   | 원문자 `①`                                       |
| `항내용` | 항 본문   | 원문자로 시작하는 문자열                         |
| `호번호` | 호 번호   | `1.`                                             |
| `호내용` | 호 본문   | `1.`로 시작하는 문자열                           |
| `목번호` | 목 번호   | `가.`                                            |
| `목내용` | 목 본문   | `가.`로 시작하는 문자열이며 끝에 줄바꿈을 포함함 |

- 계층은 `조문단위 > 항 > 호 > 목`임. 항 아래에 `항번호`, `항내용`, `호`가 있고, 호 아래에 `호번호`, `호내용`, `목`이 있음
- JSON에서 `호`와 `목`은 관측한 경우가 모두 2개 이상이라 배열이며, 1개일 때의 형태는 미확인
- JSON 루트는 `{"법령": {...}}`이고, `조문`은 `{"조문단위": [...]}`임
- 민법 본문은 XML 기준으로 1.18MB이며 조문 1193개, 전문 144개를 가짐
