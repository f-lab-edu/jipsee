## 2. S1 검색

### 구성

| 번호 | 요소        | 내용                                                                                                               |
| ---- | ----------- | ------------------------------------------------------------------------------------------------------------------ |
| 1    | 헤더        | 로고와 서비스명 "집씨"를 표시함. 검색 결과의 모바일 헤더는 로고 왼쪽에 뒤로 가기를 두고 둘째 줄에 검색창을 둠. 검색 결과의 데스크톱은 제목 패널 위에 "홈으로" 링크를 둠. 헤더는 스크롤해도 화면 위에 고정함 |
| 2    | 검색창      | 시군구명, 법정동명, 지번, 건물명을 입력함. 검색어가 비었거나 공백뿐이면 검색하지 않음. 검색어가 2자 미만이면 "검색어를 2자 이상 입력해 주세요"를 표시함 |
| 3    | 결과 목록   | 건물명(없으면 지번 주소), 지번 주소, 최근 신규 전세 계약 월을 표시함. 건물명이 없으면 지번 주소가 제목이므로 주소 줄은 중복해 표시하지 않음. 처음 20건을 보여 주고 다음 페이지가 있으면 목록 끝에 "더 보기" 버튼을 둠. 누르면 다음 20건을 목록 끝에 이어 붙이고 이미 있는 건물은 건물 id로 거름. 불러오는 중에는 버튼이 "불러오는 중"으로 바뀌고 비활성화됨. 실패하면 버튼 자리에 "일시적인 오류가 발생했어요"와 "다시 시도"를 표시함. 이어 붙이면 첫 새 건물로 포커스를 옮기고 스크린 리더에 "N건을 더 불러왔어요"를 알림. 주소(URL)는 바뀌지 않고 새 검색은 처음 20건부터 시작함. 최근 12개월 신규 전세가 없으면 모바일은 "최근 12개월 신규 전세 없음", 데스크톱은 "최근 12개월 없음"을 표시함. 결과를 누르면 S2로 이동함. 결과가 없으면 "해당 주소의 연립, 다세대 건물을 찾을 수 없어요"와 "아파트, 오피스텔은 제공하지 않아요"를 표시함 |
| 4    | 기준일      | 검색 전에는 안내 카드에, 결과가 있으면 검색창 근처 안내 상자에 "{기준 월} 실거래 정보까지 수집되어 있어요"와 "최근 1\~2개월 거래는 일부 빠져 있을 수 있어요"를 표시함. 결과가 없을 때 모바일은 표시하지 않음 |

## 3. S2 건물 상세

### 구성

| 번호 | 요소             | 내용                                                                                                                                                                                                                                                                                                                             |
| ---- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 헤더             | 1280px 미만은 로고 왼쪽에 뒤로 가기를 둔 로고 헤더이고, 건물명(없으면 주소)은 본문 첫 줄의 제목으로 표시함. 1280px 이상은 로고 헤더 아래 본문 첫 줄에 뒤로 가기와 건물명(없으면 주소)을 표시하고, 건물명이 있으면 주소도 함께 표시함. 뒤로 가기는 이전 화면으로 돌아감 |
| 2    | 외부 링크        | 공시가격알리미 링크와 안심전세 앱 링크를 표시하며 새 탭으로 열림 |
| 3    | 거래 이력        | 같은 시군구, 법정동, 지번의 전월세와 매매 거래 전체를 계약 월별 점 그래프와 거래 목록으로 표시함. 그래프 범례에 전세, 매매, 갱신, 해제를 표시하고 "월세는 목록에서 확인해요"를 안내함. 월세의 보증금과 월세는 그래프에 그리지 않고 거래 목록에만 표시함. 금액은 1억 이상이면 "1억 8,000만원"처럼 억 단위로 표시함 |
| 4    | 주변 전월세 거래 | 범위는 이 건물과 같은 법정동의 전월세 거래임. 기간은 6개월, 12개월, 24개월 중에서 고르며 기본값은 12개월임. 거래 유형은 전세와 월세 중에서 고르며 기본값은 전세임. 두 조건은 선택 상자로 고르고, 고르면 새 조건으로 다시 조회함. 면적 조건은 이 건물 거래의 전용면적 최솟값보다 10㎡ 작은 값부터 최댓값보다 10㎡ 큰 값까지로 고정하며, 사용자가 바꿀 수 없음. 면적 조건을 적용하므로 "이 건물 거래 면적 ±10㎡로 고정돼요"를 표시함. 조건에 맞는 거래 건수를 "조건에 맞는 거래 N건을 찾았어요"로 실거래 기준 월과 함께 표시함. 거래는 20건씩 표시하고 다음 거래가 있으면 "더 보기" 버튼을 표시함. 건수가 3건 미만이면 건수와 "기간을 넓혀 보세요"를 담은 안내 상자를 함께 표시하고, 0건이면 안내 상자 제목이 "조건에 맞는 거래가 없어요"임. 월세 거래에는 보증금과 월세를 표시함. 맨 아래에 "확정일자를 기준으로 수집한 거래예요. 최근 1\~2개월 거래는 일부 빠져 있을 수 있어요"를 표시함 |

## 4. S6 데이터 출처

### 구성

| 번호 | 요소           | 내용                                                                                               |
| ---- | -------------- | -------------------------------------------------------------------------------------------------- |
| 1    | 헤더           | 로고 헤더이며 1280px 미만은 로고 왼쪽에 뒤로 가기를 둠. "데이터 출처"는 본문 첫 줄 제목으로 표시함 |
| 2    | 임시 초안 안내 | 본문이 임시 안내라 "임시로 적은 안내예요. 정식 안내가 나오면 내용이 바뀔 수 있어요"를 표시함. 정식 안내로 바꿀 때 삭제함 |
| 3    | 출처 카드      | 연립다세대 전월세 실거래, 연립다세대 매매 실거래 카드 두 장을 표시함. 카드마다 데이터명, 제공 기관, "{주기} 갱신, {YYYY.MM} 기준", 원본 링크(새 탭)를 표시함 |
| 4    | 한계 안내      | 신고 및 확정일자 자료를 기반으로 하므로 거래가 누락될 수 있고, 공개가 늦어 나중에 나타나는 거래가 있을 수 있으며, 공시가격은 직접 보여 주지 않고 부동산공시가격 알리미 링크만 제공함을 안내함 |

### 데이터 출처 항목

| 데이터                   | 제공 기관                  | 갱신 | 비고                            |
| ------------------------ | -------------------------- | ---- | ------------------------------- |
| 연립다세대 전월세 실거래 | 국토교통부, 공공데이터포털 | 매일 | 이용허락범위 제한 없음. 표기 조건이 없어 제공 기관 줄이 출처 표기를 겸함 |
| 연립다세대 매매 실거래   | 국토교통부, 공공데이터포털 | 매일 | 이용허락범위 제한 없음. 표기 조건이 없어 제공 기관 줄이 출처 표기를 겸함 |
| 공시가격                 | 공시가격알리미             |      | 링크만 제공함. 출처 카드를 두지 않고 데이터 한계 안내에서 링크로 안내함 |

## 5. 공통

| 항목           | 내용                                                              |
| -------------- | ----------------------------------------------------------------- |
| 헤더           | 서비스명을 누르면 S1로 이동함. 뒤로 가기가 있는 화면은 모바일에서 로고 왼쪽에 뒤로 가기를 둠. 스크롤해도 화면 위에 고정함 |
| 푸터           | 데이터 출처 링크를 표시하고 S6에서는 링크를 굵게 표시함. 모바일과 태블릿(1280px 미만)에서는 화면 아래에 고정함 |
| 흰 세로 열     | 모바일과 태블릿(1280px 미만)에서 헤더부터 푸터까지 흰색 열 하나가 감쌈. 열 폭은 480(768 이상은 720)이고 하늘빛 배경은 열 바깥에만 보임. 헤더 아래에 구분선과 그림자를 둠. |
| 오류           | "일시적인 오류가 발생했어요"를 표시하고 "다시 시도"(서버 데이터를 다시 요청함)와 "홈으로 가기"를 둠. 헤더와 푸터는 그대로 둠. 검색 결과는 결과 영역만 오류로 바꾸고 검색창은 그대로 두며 "다시 시도"만 둠 |
| 404            | 없는 주소와 없는 건물은 "페이지를 찾을 수 없어요"와 "주소가 바르지 않거나 삭제된 페이지예요"를 표시하고 "홈으로 가기"를 둠. 헤더와 푸터는 그대로 둠 |
| 금액 표시      | 만원 단위 금액을 1억 이상은 "1억 8,000만원", 나머지가 0이면 "2억", 1억 미만은 "9,500만원"으로 표시함 |
