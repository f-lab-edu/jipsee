## 1. 화면 목록

| 화면         | 담당 기능                                        | 진입                                     |
| ------------ | ------------------------------------------------ | ---------------------------------------- |
| S1 검색      | 건물 검색                                        | 첫 화면                                  |
| S2 건물 상세 | 거래 이력, 주변 전월세 거래, 공시가격알리미 링크 | S1 검색 결과, 챗봇 답변의 건물 링크      |
| S3 챗봇      | 챗봇 대화, 법령 검색, 주제 제한                  | S1 하단 입력창, S2 질문하기              |
| S4 로그인    | 로그인 (구글, 카카오, 네이버)                    | 헤더 로그인, 비로그인 상태에서 챗봇 진입 |
| S5 내 정보   | 로그아웃, 회원 탈퇴                              | 헤더 프로필                              |
| S6 정책      | 이용약관, 개인정보처리방침, 데이터 출처          | 푸터, S4 고지, S5                        |
| 공통         | 요청 제한, 봇 차단, 기준일 표시                  | 모든 화면                                |

## 2. S1 검색

![S1 검색 와이어프레임](./screen-spec/s1-search-wireframe.svg)

### 구성

| 번호 | 요소        | 내용                                                           |
| ---- | ----------- | -------------------------------------------------------------- |
| 1    | 헤더        | 서비스명, 로그인 버튼 (로그인 후 프로필)                       |
| 2    | 검색창      | 도로명 주소, 지번 주소, 건물명 입력 (2글자 이상)               |
| 3    | 결과 목록   | 건물명, 주소, 사용승인 연도, 최근 신규 전세 계약 월. 누르면 S2 |
| 4    | 기준일      | 실거래 기준 월, 최근 1\~2개월 누락 안내                        |
| 5    | 챗봇 입력창 | 예시 질문. 비로그인이면 S4                                     |

### 유저 플로우

![건물 검색 유저 플로우](./screen-spec/s1-search-flow.svg)

## 3. S2 건물 상세

![S2 건물 상세 와이어프레임](./screen-spec/s2-building-wireframe.svg)

### 구성

| 번호 | 요소             | 내용                                                                                                                                                                                                                                                                                                                                 |
| ---- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | 헤더             | 뒤로, 건물명                                                                                                                                                                                                                                                                                                                         |
| 2    | 건물 정보        | 사용승인 연도, 세대수, 층수, 연면적, 구조, 내진설계, 승강기, 주차 대수, 기타용도, 건축물대장 기준 월. 원본이 0이거나 없으면 숨기고 승강기는 0이면 "없음" 표시                                                                                                                                                                        |
| 3    | 공시가격         | 공시가격알리미 링크. 값은 표시하지 않음                                                                                                                                                                                                                                                                                              |
| 4    | 거래 이력        | 계약 월별 점 그래프(전세, 매매만. 거래 1건 = 점 1개, 평균 없음)와 거래 목록(전세, 월세, 매매 구분. 월세는 보증금과 월세를 목록에만 표시). 갱신, 해제, 유사 건물로 연결, 이전 건물 표시                                                                                                                                               |
| 5    | 주변 전월세 거래 | 반경 300m, 500m, 1km (기본 500m), 면적 ±10㎡, 기간 6, 12, 24개월 (기본 12개월), 거래 유형(전세, 월세 중 선택, 기본 전세). 매칭이 확정된 거래만 포함, 원본 필드 목록(월세는 보증금과 월세), 선택한 유형 기준 건수, 기준일, 확정일자 기반 안내. 건물 좌표가 없으면 "이 건물은 위치 정보가 없어 주변 거래를 보여드릴 수 없습니다." 표시 |
| 6    | 질문하기         | 이 건물을 넣은 상태로 S3 이동. 비로그인이면 S4                                                                                                                                                                                                                                                                                       |

## 4. S3 챗봇

![S3 챗봇 와이어프레임](./screen-spec/s3-chatbot-wireframe.svg)

### 구성

| 번호 | 요소    | 내용                                                                     |

| 4    | 입력창  | 질문 입력, 전송. 답변 중에는 전송 막음                                   |

## 6. S6 정책

![S6 정책 와이어프레임](./screen-spec/s6-policy-wireframe.svg)

### 구성

| 번호          | 요소      | 내용                                                    |
| ------------- | --------- | ------------------------------------------------------- |
| 1             | 헤더      | 뒤로, 문서명                                            |
| 2             | 시행일    | 시행일, 이전 버전 목록                                  |
| 3             | 목차      | 누르면 해당 항목으로 이동                               |
| 4             | 본문      | 항목별 내용                                             |
| 데이터 출처 1 | 출처 카드 | 데이터명, 제공 기관, 갱신 주기, 현재 기준 월, 원본 링크 |
| 데이터 출처 2 | 한계 안내 | 확정일자 기반 누락, 공개 지연, 공시가격 링크만 제공     |

### 유저 플로우

![정책 열람 유저 플로우](./screen-spec/s6-policy-flow.svg)

### 개인정보처리방침 항목

| 항목             | Jipsee 내용                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 처리 목적        | 회원 식별, 챗봇 제공, 요청 제한, 부정 이용 방지                                                        |
| 처리 항목        | 로그인 제공자, 제공자 사용자 ID, 챗봇 대화 내용, 접속 IP, 접속 기록                                    |
| 보유 기간, 파기  | 계정은 탈퇴 시까지. 대화, 접속 기록 보관 기간(미정). 탈퇴 시 즉시 삭제, 백업은 보관 기간이 지나면 삭제 |
| 처리 위탁        | Oracle(서버), Cloudflare(CDN, 봇 차단), LLM 제공사(미정), Sentry(오류 추적)                            |
| 국외 이전        | 이전받는 자별로 법적 근거, 항목, 국가, 시기와 방법, 연락처, 목적과 보유 기간, 거부 방법과 효과         |
| 쿠키             | 로그인 세션 쿠키. 거부 시 로그인 불가                                                                  |
| 정보주체 권리    | 열람, 정정, 삭제, 처리정지 요청 방법. 탈퇴는 S5                                                        |
| 안전성 확보 조치 | HTTPS, 서버 접근 제한, 비밀값 분리                                                                     |
| 보호책임자       | 운영자 이름, 연락 이메일                                                                               |
| 변경             | 시행일, 이전 버전 보관                                                                                 |

### 이용약관 항목

| 항목        | Jipsee 내용                                                     |
| ----------- | --------------------------------------------------------------- |
| 서비스 내용 | 공공데이터 조회, 챗봇. 계산, 판단, 법률 자문 제공 안 함         |
| 회원        | 구글, 카카오, 네이버 로그인으로 가입. S5에서 탈퇴               |
| 이용 제한   | 자동화 수집, 요청 제한 초과, 지시 조작 시도 시 제한             |
| 데이터 한계 | 원본 그대로 제공. 누락, 공개 지연, 유사 건물로 연결된 거래 가능 |
| 챗봇        | 답변은 일반 정보. 외부 LLM 사용. 일일 한도                      |
| 책임        | 무료 서비스. 정보 이용 결과에 대한 책임 범위                    |
| 변경, 분쟁  | 변경 시 사전 공지, 준거법 대한민국                              |

## 7. 공통

| 항목           | 내용                                                |
| -------------- | --------------------------------------------------- |
| 헤더           | 서비스명(누르면 S1), 로그인 또는 프로필(S5)         |
| 푸터           | 데이터 출처, 이용약관, 개인정보처리방침             |
| 기준일         | 실거래, 건축물대장 값이 나오는 모든 곳에 기준 월    |
| 요청 제한 초과 | "요청이 많습니다. 잠시 후 다시 시도해 주세요"       |
| 봇 차단        | Turnstile. 평소에는 안 보이고 의심될 때만 확인 표시 |
| 오류           | "일시적인 오류가 발생했습니다"와 다시 시도          |
| 정책 페이지    | S6 참고                                             |
