## 1. 개요

공공데이터를 가져와 화면과 챗봇으로 그대로 보여주는 연립, 다세대 전세 정보 서비스

| 항목       | 내용                                                           |
| ---------- | -------------------------------------------------------------- |
| 이름       | Jipsee (집씨). 집(jip)과 보다(see)를 합친 이름                 |
| 역할       | 데이터를 가져와서 UI와 챗봇으로 알려줌                         |
| 데이터     | 실거래, 건축물대장, 법령                                       |
| 목표 1순위 | 백엔드 설계, 배포, 운영 경험. 핵심 과제는 데이터 매칭과 정합성 |
| 목표 2순위 | 실사용자 확보                                                  |
| 범위       | 전국 연립, 다세대 전세 (아파트, 오피스텔 제외)                 |

### 표시 원칙

| 원칙      | 내용                                                                          |
| --------- | ----------------------------------------------------------------------------- |
| 원본만    | 원본 데이터만 표시. 계산, 통계, 추정값 없음                                   |
| 판단 금지 | 판단, 결론 문구 금지 (적정, 위험, 이내, 가능 등)                              |
| 조건 선택 | 비교 조건은 사용자가 선택. 기본값도 화면에 표시                               |
| 출처      | 모든 수치에 출처와 기준일 표시                                                |
| 챗봇 범위 | 서비스 범위 밖 질문에 답하지 않음. 법령은 일반 정보까지, 개별 사건 판단 안 함 |

### 챗봇 답변 예시

| 구분 | 예시                                                                                                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 허용 | 반경 500m, 35\~45㎡, 최근 12개월 조건의 전세 거래는 14건입니다. \[거래 목록: 건물명, 거리, 면적, 층, 보증금, 계약 월, 신규/갱신\] (출처: 국토교통부 실거래가, 2026년 9월 기준) |
| 허용 | 임차인은 임대차기간이 끝나기 6개월 전부터 2개월 전까지 계약갱신을 요구할 수 있습니다. (주택임대차보호법 제6조의3 제1항, 제6조 제1항)                                           |
| 금지 | 주변 시세로 보면 적정 보증금은 2.5억 정도입니다. / 보증보험 가입 가능합니다.                                                                                                   |

## 2. 타겟 사용자

주소를 이미 아는 연립, 다세대 전세 세입자

| 사용자         | 수요                                                   | Jipsee가 주는 것                                       |
| -------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| 계약 전 세입자 | 이 건물과 주변 전세 거래 금액, 계약 절차               | 건물 거래 이력, 주변 전세 거래, 건물 정보, 법령과 절차 |
| 갱신 전 세입자 | 최근 같은 건물, 주변 전세 거래, 갱신요구권과 증액 규정 | 같음. 법령 안내 비중이 큼                              |

### 범위 밖 사용자

| 사용자                           | 필요한 것                           | 안내할 곳                     |
| -------------------------------- | ----------------------------------- | ----------------------------- |
| 동네를 고르는 사람               | 지도, 지역별 비교, 순위             | 직방, 다방, 네이버 부동산     |
| 집의 안전 여부를 확인하려는 사람 | 등기부, 임대인 정보, 보증 가입 여부 | 안심전세 앱. 건물 상세에 링크 |

## 3. 사용자 시나리오

### 계약 전 세입자

| 단계 | 행동                                                                        |
| ---- | --------------------------------------------------------------------------- |
| 1    | 중개사가 보여준 주소를 검색                                                 |
| 2    | 건물 상세에서 사용승인일, 과거 전세, 매매 거래 확인                         |
| 3    | 반경 500m, 비슷한 면적, 최근 12개월 조건으로 주변 전세 거래 조회            |
| 4    | 챗봇에 "이 건물 최근 2년 전세 거래 알려줘", "전입신고는 언제 해야 해?" 질문 |
| 5    | 공시가격, 등기부는 링크로 이동해 확인                                       |

### 갱신 전 세입자

| 단계 | 행동                                                                               |
| ---- | ---------------------------------------------------------------------------------- |
| 1    | 지금 사는 집 주소를 검색                                                           |
| 2    | 같은 건물의 최근 신규, 갱신 전세 거래 확인                                         |
| 3    | 챗봇에 "갱신요구권은 언제까지 쓸 수 있어?", "보증금을 얼마까지 올릴 수 있어?" 질문 |
| 4    | 답변에 붙은 조문과 출처를 보고 직접 판단                                           |

## 4. 화면

화면은 검색, 건물 상세, 챗봇 3개.

| ID  | 화면      | 내용                                                                        |
| --- | --------- | --------------------------------------------------------------------------- |
| S1  | 검색      | 주소, 건물명 검색과 결과 목록, 챗봇 입력창, 로그인                          |
| S2  | 건물 상세 | 건물 정보, 거래 이력, 주변 전세 거래 목록, 공시가격알리미 링크, 질문하기    |
| S3  | 챗봇      | 건물 데이터, 법령, 절차 질문과 답변, 출처, 건물 상세 바로가기 (로그인 필요) |

### 유저 플로우 (화면)

1. 도로명 주소, 지번 주소, 건물명으로 검색
2. 건물 상세에서 건물 정보, 거래 이력 확인
3. 반경, 면적, 기간을 골라 주변 전세 거래 목록 조회
4. 공시가격은 공시가격알리미 링크로 확인

### 유저 플로우 (챗봇)

1. 로그인 후 검색 화면 하단 입력창이나 건물 상세의 "질문하기"로 시작
2. 건물 데이터 질문은 화면과 같은 조회 결과로, 법령, 절차 질문은 관련 조문과 출처로 답변
3. 답변 속 건물 이름을 눌러 건물 상세로 이동

## 5. 기능

| 기능            | 설명                                                                  |
| --------------- | --------------------------------------------------------------------- |
| 실거래 수집     | 전국 연립, 다세대 전월세, 매매 수집과 정리                            |
| 건축물대장 저장 | 건축물대장 표제부 저장 (지번 주소, 도로명 주소 포함)                  |
| 건물 매칭       | 실거래와 건축물대장을 같은 건물로 연결, 건물마다 자체 ID 발급         |
| 법령 저장       | 주택임대차 관련 법령, 판례를 조문 단위로 저장                         |
| 건물 검색       | 도로명 주소, 지번 주소, 건물명으로 건물 찾기                          |
| 거래 이력       | 건물의 전세, 매매 거래 목록과 계약 월별 점 그래프 (거래 1건 = 점 1개) |
| 주변 전세 거래  | 사용자가 고른 조건의 주변 전세 거래 목록                              |
| 챗봇 대화       | 질문, 답변 스트리밍. 도구로 조회 기능과 법령 검색 호출                |
| 법령 검색       | 법령명, 조문 번호, 키워드 검색                                        |
| 답변 품질 검증  | 평가 세트로 답변 자동 검사                                            |
| 주제 제한       | 범위 밖 질문 차단                                                     |
| 요청 제한       | 화면 API, 챗봇 요청 수 제한, 챗봇 일일 한도, LLM 비용 상한            |
| 로그인          | 챗봇 이용 시 필수, 구글 로그인                                        |
| 봇 차단         | 화면, 챗봇 자동화 요청 차단                                           |

## 6. 기능별 완료 기준

| 기능            | 완료 기준                                                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 실거래 수집     | 전국 시군구의 과거 전월세, 매매가 저장되고, 매일 수집이 실패 없이 돌며, 같은 시군구와 계약 월을 다시 수집해도 건수가 변하지 않음 |
| 건축물대장 저장 | 전국 표제부가 저장되고 매월 변동분 반영 후 건축HUB 건수와 일치                                                                   |
| 건물 매칭       | 모든 거래가 **확정, 추정, 이전 건물, 실패** 중 하나로 분류되고, 표본 검수 정확도가 기준(미정) 이상                               |
| 법령 저장       | 주택임대차보호법과 시행령, 전세사기피해자 특별법, 민법 임대차 조항이 조문 단위로 저장되고, 법 개정 시 해당 법만 다시 저장됨      |
| 건물 검색       | 도로명 주소, 지번 주소, 건물명 어느 것으로 검색해도 같은 건물이 나오고, 결과 없음과 추정 매칭이 표시됨                           |
| 거래 이력       | 건물의 모든 거래가 목록과 점 그래프에 나오고, 갱신, 해제, 현재 건물 이전 거래가 구분됨                                           |
| 주변 전세 거래  | 반경, 면적, 기간을 바꾸면 조건에 맞는 거래 목록, 건수, 기준일이 표시되고, 3건 미만이면 조건 넓히기 안내가 나옴                   |
| 챗봇 대화       | 답변이 스트리밍으로 나오고, 수치는 도구 결과와 같으며, 모든 답변에 출처와 기준일이 있음                                          |
| 법령 검색       | 법령명, 조문 번호, 키워드로 해당 조문을 찾음                                                                                     |
| 답변 품질 검증  | 평가 세트 50\~100문항이 자동으로 돌고 통과율이 기준(미정) 이상                                                                   |
| 주제 제한       | 범위 밖 질문과 지시 조작 시도에 정해진 안내 문구로 답하고 본 LLM을 호출하지 않음                                                 |
| 요청 제한       | 한도를 넘은 요청에 429가 나오고, 서버 2개에 나눠 보내도 한도가 합산되며, 일, 월 LLM 비용 상한에서 챗봇이 멈춤                    |
| 로그인          | 구글 로그인 없이 챗봇 호출이 막히고, 배포 후에도 로그인이 유지됨                                                                 |
| 봇 차단         | Turnstile 토큰이 없거나 가짜인 요청이 서버에서 거부됨                                                                            |

## 7. 운영 지표

초기 목표. 첫 배포 후 실제 수치를 보고 조정. 2주마다 확인해 가장 문제인 부분 1개를 개선하고 개선 전후 수치 기록.

| 지표                                                             | 목표                   |
| ---------------------------------------------------------------- | ---------------------- |
| 건물 매칭 정확도 (표본 수동 검수)                                | 미정 (검수 후 설정)    |
| 건물 매칭 성공률                                                 | 추적                   |
| 건물 상세 조회 p95                                               | 200ms                  |
| 주변 전세 거래 조회 p95                                          | 500ms                  |
| 챗봇 첫 응답 시작                                                | 2초                    |
| 평가 세트 통과율                                                 | 미정                   |
| LLM 비용                                                         | 미정 (대화당, 월 상한) |
| 수집 작업 성공률                                                 | 99%                    |
| 공공데이터 공개 후 Jipsee 반영 (원천 지연 제외)                  | 24시간 이내            |
| 방문자, 검색 수, 챗봇 대화 수, 요청 제한 초과율                  | 추적만                 |
| 검색 후 건물 상세 진입률, 거래 0건 건물 조회 비율, 챗봇 재사용률 | 추적만 (초안 추가)     |

## 8. 출시 기준

| --------- | ------------------------------------------------------------------------------------------------------- |

| 매칭      | 시군구별 표본 검수 정확도가 기준(미정) 이상                                                             |

| 화면 안내 | 기준일, "최근 1\~2개월 거래는 일부 빠져 있을 수 있음", "확정일자 기반" 안내 표시                        |
