## 1. 개요

공공데이터를 가져와 화면과 챗봇으로 그대로 보여주는 연립, 다세대 전월세 정보 서비스

| 항목       | 내용                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| 이름       | Jipsee (집씨). 집(jip)과 보다(see)를 합친 이름                                       |
| 데이터     | 실거래, 건축물대장, 법령                                                             |
| 목표 1순위 | 백엔드를 설계, 배포, 운영하는 경험을 쌓음. 핵심 과제는 데이터 매칭과 데이터 정합성임 |
| 목표 2순위 | 실제 사용자를 확보함                                                                 |
| 범위       | 전국 연립, 다세대 전월세를 대상으로 하고, 아파트와 오피스텔은 제외함                 |

### 표시 원칙

| 원칙      | 내용                                                                  |
| --------- | --------------------------------------------------------------------- |
| 원본만    | 원본 데이터만 표시함. 계산값, 통계, 추정값은 표시하지 않음            |
| 판단 금지 | 판단이나 결론을 나타내는 문구를 쓰지 않음 (적정, 위험, 이내, 가능 등) |
| 조건 선택 | 비교 조건은 사용자가 선택함. 기본값도 화면에 표시함                   |
| 출처      | 모든 수치에 출처와 기준일을 표시함                                    |
| 법령 답변 | 일반 정보까지만 답하고, 개별 사건은 판단하지 않음                     |

### 챗봇 답변 예시

| 구분 | 예시                                                                                                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 허용 | 반경 500m, 35\~45㎡, 최근 12개월 조건의 전세 거래는 14건입니다. \[거래 목록: 건물명, 거리, 면적, 층, 보증금, 계약 월, 신규/갱신\] (출처: 국토교통부 실거래가, 2026년 9월 기준) |
| 허용 | 임차인은 임대차기간이 끝나기 6개월 전부터 2개월 전까지 계약갱신을 요구할 수 있습니다. (주택임대차보호법 제6조의3 제1항, 제6조 제1항)                                           |
| 금지 | 주변 시세로 보면 적정 보증금은 2.5억 정도입니다. / 보증보험 가입 가능합니다.                                                                                                   |

## 2. 타겟 사용자

주소를 이미 알고 있는 연립, 다세대 전월세 세입자

| 사용자         | 수요                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| 계약 전 세입자 | 이 건물과 주변 전월세 거래 금액, 계약 절차를 알고 싶음                             |
| 갱신 전 세입자 | 같은 건물의 최근 전월세 거래, 주변 전월세 거래, 갱신요구권과 증액 규정을 알고 싶음 |

### 범위 밖 사용자

| 사용자                           | 필요한 것                           | 안내할 곳                               |
| -------------------------------- | ----------------------------------- | --------------------------------------- |
| 동네를 고르는 사람               | 지도, 지역별 비교, 순위             | 직방, 다방, 네이버 부동산               |
| 집의 안전 여부를 확인하려는 사람 | 등기부, 임대인 정보, 보증 가입 여부 | 안심전세 앱. 건물 상세 화면에 링크를 둠 |

## 3. 사용자 시나리오

### 계약 전 세입자

1. 중개사가 보여준 주소를 검색함
2. 건물 상세에서 사용승인일, 과거 전월세 거래, 매매 거래를 확인함
3. 반경 500m, 비슷한 면적, 최근 12개월 조건으로 주변 전월세 거래를 조회함
4. 챗봇에 "이 건물 최근 2년 전세 거래 알려줘", "전입신고는 언제 해야 해?"를 질문함
5. 공시가격과 등기부는 링크로 이동해 확인함

### 갱신 전 세입자

1. 지금 사는 집 주소를 검색함
2. 같은 건물의 최근 신규 전월세 거래와 갱신 전월세 거래를 확인함
3. 챗봇에 "갱신요구권은 언제까지 쓸 수 있어?", "보증금을 얼마까지 올릴 수 있어?"를 질문함
4. 답변에 붙은 조문과 출처를 보고 직접 판단함

## 4. 기능과 완료 기준

| 기능             | 완료 기준                                                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 실거래 수집      | 전국 시군구의 과거 전월세와 매매 거래가 저장되고, 매일 수집이 실패 없이 실행되며, 같은 시군구와 계약 월을 다시 수집해도 건수가 변하지 않음                                                              |
| 건축물대장 저장  | 연립이나 다세대가 있는 필지의 표제부가 저장되고, 매월 변동분을 반영한 뒤의 저장 건수가 저장 범위 안의 건축HUB 건수와 일치함                                                                             |
| 건물 매칭        | 실거래와 건축물대장이 같은 건물로 연결되고, 모든 거래가 **확정, 추정, 이전 건물, 실패** 중 하나로 분류되며, 표본 검수 정확도가 기준(미정) 이상임                                                        |
| 법령 저장        | 주택임대차보호법과 시행령, 전세사기피해자 특별법, 민법 임대차 조항이 조문 단위로 저장되고, 법이 개정되면 개정된 법만 다시 저장됨                                                                        |
| 건물 검색        | 도로명 주소, 지번 주소, 건물명 어느 것으로 검색해도 같은 건물이 나오고, 검색 결과가 없으면 없다는 사실이 표시됨                                                                                         |
| 거래 이력        | 건물의 전세, 월세, 매매 거래 목록과 계약 월별 점 그래프가 표시됨. 점 그래프에는 전세와 매매만 거래 1건당 점 1개로 표시되고, 갱신 거래, 해제 거래, 유사 건물로 연결된 거래, 이전 건물 거래가 서로 구분됨 |
| 주변 전월세 거래 | 반경, 면적, 기간, 거래 유형(전세, 월세)을 바꾸면 선택한 유형에 해당하는 매칭 확정 거래의 목록, 건수, 기준일이 표시되고, 3건 미만이면 조건을 넓히도록 안내함                                             |
| 챗봇 대화        | 답변이 스트리밍으로 표시되고, 수치가 도구 결과와 같으며, 모든 답변에 출처와 기준일이 포함됨                                                                                                             |
| 법령 검색        | 법령명, 조문 번호, 키워드로 해당 조문을 찾을 수 있음                                                                                                                                                    |
| 답변 품질 검증   | 50\~100문항의 평가 세트로 답변을 자동 검사하고, 통과율이 기준(미정) 이상임                                                                                                                              |
| 주제 제한        | 범위 밖 질문과 지시를 조작하려는 시도에는 정해진 안내 문구로 답하고, 본 LLM을 호출하지 않음                                                                                                             |
| 요청 제한        | 화면 API 요청 수, 챗봇 요청 수, 챗봇 일일 한도를 넘은 요청에는 429가 반환되고, 서버 2개에 나눠 보내도 한도가 합산되며, LLM 비용이 일 단위나 월 단위 상한에 도달하면 챗봇이 멈춤                         |
| 로그인           | 구글, 카카오, 네이버 계정으로 로그인할 수 있고, 로그인하지 않으면 챗봇 호출이 막히며, 배포한 뒤에도 로그인 상태가 유지됨                                                                                |
| 봇 차단          | Turnstile 토큰이 없거나 가짜인 요청이 서버에서 거부됨                                                                                                                                                   |

## 5. 운영 지표

초기 목표이며, 첫 배포 후 실제 수치를 보고 조정함. 2주마다 확인해 가장 문제인 부분 1개를 개선하고, 개선 전후 수치를 기록함.

| 지표                                                             | 목표                   |
| ---------------------------------------------------------------- | ---------------------- |
| 건물 매칭 정확도 (표본 수동 검수)                                | 미정 (검수 후 설정)    |
| 건물 매칭 성공률                                                 | 추적                   |
| 건물 상세 조회 p95                                               | 200ms                  |
| 주변 전월세 거래 조회 p95                                        | 500ms                  |
| 챗봇 첫 응답 시작 시간                                           | 2초                    |
| 평가 세트 통과율                                                 | 미정                   |
| LLM 비용                                                         | 미정 (대화당, 월 상한) |
| 수집 작업 성공률                                                 | 99%                    |
| 공공데이터 공개 후 Jipsee 반영까지 걸리는 시간 (원천 지연 제외)  | 24시간 이내            |
| 방문자, 검색 수, 챗봇 대화 수, 요청 제한 초과율                  | 추적만                 |
| 검색 후 건물 상세 진입률, 거래 0건 건물 조회 비율, 챗봇 재사용률 | 추적만 (초안 추가)     |

## 6. 출시 기준

| 영역      | 기준                                                                                                                 |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| 데이터    | 전국 실거래와 표제부의 저장을 완료함. 매일 수집이 7일 연속 성공함                                                    |
| 매칭      | 시군구별 표본 검수 정확도가 기준(미정) 이상임                                                                        |
| 챗봇      | 평가 세트 통과율이 기준(미정) 이상임. 판단 문구와 출처 누락이 0건임                                                  |
| 성능      | 부하 테스트에서 운영 지표의 응답 시간 목표를 충족함                                                                  |
| 보호      | 요청 제한, 로그인, 봇 차단, LLM 비용 상한이 실제 환경에서 동작함                                                     |
| 운영      | 배포 중 서비스가 중단되지 않음. 로그, 지표, 알림이 동작함. DB 백업 복원이 1회 성공함                                 |
| 법적 고지 | 개인정보처리방침을 게시하고(국외 이전 항목 포함), 챗봇 입력이 외부 LLM으로 전송된다고 고지하며, 데이터 출처를 표기함 |
| 화면 안내 | 기준일, 최근 1\~2개월 거래의 일부 누락 가능성, 확정일자 기반 안내를 표시함                                           |
