## 1. 개요

공공데이터를 가져와 화면으로 그대로 보여주는 연립, 다세대 전월세 정보 서비스

| 항목       | 내용                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 이름       | Jipsee (집씨). 집(jip)과 보다(see)를 합친 이름                               |
| 데이터     | 실거래                                                                       |
| 목표 1순위 | 백엔드를 설계, 배포, 운영하는 경험을 쌓음. 핵심 과제는 데이터 정합성임       |
| 목표 2순위 | 실제 사용자를 확보함                                                         |
| 범위       | 전국 연립, 다세대 전월세를 대상으로 하고, 아파트와 오피스텔은 제외함         |

### 건물 단위

- 화면에 표시하는 건물은 시군구 코드, 법정동명, 지번이 같은 실거래 묶음
- 건물명은 묶음에서 계약일이 가장 늦은 거래의 건물명으로 표시하고, 건물명이 없으면 지번 주소(`{시군구명} {법정동명} {지번}`)로 대체

### 표시 원칙

| 원칙      | 내용                                                                  |
| --------- | --------------------------------------------------------------------- |
| 원본만    | 원본 데이터만 표시함. 계산값, 통계, 추정값은 표시하지 않음            |
| 판단 금지 | 판단이나 결론을 나타내는 문구를 쓰지 않음 (적정, 위험, 이내, 가능 등) |
| 조건 선택 | 비교 조건은 사용자가 선택함. 기본값도 화면에 표시함                   |
| 출처      | 모든 수치에 출처와 기준일을 표시함                                    |

## 2. 타겟 사용자

주소를 이미 알고 있는 연립, 다세대 전월세 세입자

| 사용자         | 수요                                                  |
| -------------- | ----------------------------------------------------- |
| 계약 전 세입자 | 이 건물과 주변 전월세 거래 금액을 알고 싶음           |
| 갱신 전 세입자 | 같은 건물의 최근 전월세 거래와 주변 전월세 거래를 알고 싶음 |

### 범위 밖 사용자

| 사용자                           | 필요한 것                           | 안내할 곳                               |
| -------------------------------- | ----------------------------------- | --------------------------------------- |
| 동네를 고르는 사람               | 지도, 지역별 비교, 순위             | 직방, 다방, 네이버 부동산               |
| 집의 안전 여부를 확인하려는 사람 | 등기부, 임대인 정보, 보증 가입 여부 | 안심전세 앱. 건물 상세 화면에 링크를 둠 |

## 3. 사용자 시나리오

### 계약 전 세입자

1. 중개사가 보여준 주소를 검색함
2. 건물 상세에서 과거 전월세 거래, 매매 거래를 확인함
3. 같은 법정동, 비슷한 면적, 최근 12개월 조건으로 주변 전월세 거래를 조회함
4. 공시가격과 등기부는 링크로 이동해 확인함

### 갱신 전 세입자

1. 지금 사는 집 주소를 검색함
2. 같은 건물의 최근 신규 전월세 거래와 갱신 전월세 거래를 확인함

## 4. 기능과 완료 기준

| 기능             | 완료 기준                                                                                                                                                                                                              |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 실거래 수집      | 전국 시군구의 과거 전월세와 매매 거래가 저장되고, 매일 수집이 실패 없이 실행되며, 같은 시군구와 계약 월을 다시 수집해도 건수가 변하지 않음                                                                             |
| 건물 검색        | 건물명이나 지번 주소(시군구명, 법정동명, 지번)로 검색하면 일치하는 건물을 20건씩 표시하고, 일치하는 건물이 없으면 없다는 사실을 표시                                                                                    |
| 거래 이력        | 건물명, 지번 주소, 해당 건물에 속한 전세, 월세, 매매 거래 목록과 계약 월별 점 그래프를 표시. 점 그래프에는 전세와 매매만 거래 1건당 점 1개로 표시하고, 갱신 거래와 해제 거래를 서로 구분                                |
| 주변 전월세 거래 | 기간(6, 12, 24개월)과 거래 유형(전세, 월세)을 바꾸면 같은 법정동에서 기준 건물 거래의 전용면적 기준 ±10㎡ 범위에 해당하는 전월세 거래의 목록, 전체 건수, 기준일을 20건씩 표시하고, 3건 미만이면 조건을 넓히도록 안내 |

## 5. 운영 지표

초기 목표이며, 첫 배포 후 실제 수치를 보고 조정함. 2주마다 확인해 가장 문제인 부분 1개를 개선하고, 개선 전후 수치를 기록함.

| 지표                                                            | 목표                |
| --------------------------------------------------------------- | ------------------- |
| 건물 상세 조회 p95                                              | 200ms               |
| 주변 전월세 거래 조회 p95                                       | 500ms               |
| 수집 작업 성공률                                                | 99%                 |
| 공공데이터 공개 후 Jipsee 반영까지 걸리는 시간 (원천 지연 제외) | 24시간 이내         |
| 방문자, 검색 수                                                 | 추적만              |
| 검색 후 건물 상세 진입률                                        | 추적만 (초안 추가)  |

## 6. 출시 기준

| 영역      | 기준                                                                    |
| --------- | ----------------------------------------------------------------------- |
| 데이터    | 전국 실거래 저장이 완료되고, 매일 수집이 7일 연속 성공                  |
| 성능      | 부하 테스트에서 운영 지표의 응답 시간 목표를 충족함                     |
| 운영      | 배포 중 서비스가 중단되지 않음. 로그, 지표, 알림이 동작함. DB 백업 복원이 1회 성공함 |
| 법적 고지 | 데이터 출처를 표기함                                                    |
| 화면 안내 | 기준일, 최근 1\~2개월 거래의 일부 누락 가능성, 신고 및 확정일자 자료 기반 안내를 표시함 |

출시 기준은 서비스 공개 시점에 적용함. 공개 전에 배치 앱만 먼저 띄우는 배포(`infra/README.md`)에는 운영 기준을 적용하지 않음
